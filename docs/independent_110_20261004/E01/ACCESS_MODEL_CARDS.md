## One existing structural escape: coherent Sobol coordinates (F05)

The proposed interface loads 32-bit coordinate words x = M i over F2 from a q-bit uniform label, retaining i and clean coordinate targets, then calls the same native graph and selector. It prepares q label Hadamards and L = popcount(M) CNOTs; each literal loader inverse has the same L count. M, its coordinate ordering, digital shifts/scrambles and an emitted clean circuit are absent for these exact B4/B8 inputs. L therefore remains null. The source forward/inverse and payoff operations remain required on every estimation iterate. Under the unchanged 15-shot/65,535-step recipe, loader use is (15 + 2*983025)*L; this is symbolic accounting, not an executable candidate cost. The new label/coordinate reflection and its workspace are separately unbuilt. Matrix acquisition/validation, transforms, bias certification, confidence schedule, decoding and all setup for this one delivered price must be paid without amortizing across invented later requests.

A q-bit label has at most 2^q input patterns and a binary linear map has rank at most q. The original product law has 2^(32D) equally likely word patterns. For fixed diagnostics q=16 or 32 and D=60 or 468, the proposed net cannot equal that joint input law. Matching each marginal is insufficient. This proves an access-law mismatch, not a nonzero price bias: a particular payoff can have equal means under distinct laws. A source-specific pushforward equality or a charged dollar-bias certificate is still required. The original continuous/native certificate does not transfer automatically.

The existing classical Sobol/PCA implementation instead uses 48/416 normals and inverse-normal/PCA arithmetic. Continuous covariance equivalence does not establish equivalence with this finite paired-Box-Muller native output. Reusing that preprocessing coherently would require another explicit reversible reduction; it is not supplied by its classical Python code. Endpoint handling must also match the original 32-bit midpoint convention.

Their numerical functions are linear; this does not supply the repository's monitored arithmetic-basket graph or its bias certificate. Their source and inverse query convention includes both directions. The locally pinned paper is `primary_sources/Recchia_2609_03625v1.pdf`.
