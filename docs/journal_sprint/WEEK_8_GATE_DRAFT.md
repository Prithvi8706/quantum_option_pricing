# Week 8 entry gate after the failed broad-utility screen

Historical entry draft. Subsequently implemented as [week-8 plan](WEEK_8_PLAN.md)
and [prospective pilot](PROTOCOL_W8_REPRESENTATION.md); see [results](WEEK_8_RESULTS.md).

Draft, not executed. Week 7 completed the planned bounded ablation and comparator
scope decision; it did not make the original large main matrix scientifically ready.

The current fixed representation/schedules provide frequent $1 delivery mainly
for E001. Do not simply raise shot budgets again or select a favorable nuisance
allowance and call that adaptation. The eight rare E025 arm declarations must
remain visible; non-delivery does not establish impossibility.

Next local work should audit which claims a narrower reliability/resource study
can support, and whether representation or inference conservatism is the relevant
next lever. Start from the existing deterministic-bound/cost menu and full-branch
sets. Exact targets may diagnose the limitations after decisions, never rank
candidate representations or schedules for a deployable controller.

Before any new draws, specify a small fresh protocol with an observation-safe
selection interface, a total setup/pilot/calibration/validation cost ledger, and
an explicit baseline. If no defensible candidate improves useful delivery under
the stated assumptions, retain the negative result and narrow the paper claim.

Native BAE/BIQAE ideal-response exploratory comparisons are possible only after
declaring matched targets, actual stopping/overshoot costs, output semantics and
randomness limitations. A calibration-aware extension would be a modified method,
not an already-validated native baseline. The week-7 scope audit supplies exact
pinned evidence; no native head-to-head result is claimed from that audit.

Main confirmation, numerical certification, realistic transfer justification,
human contributor work/approval, novelty and external review remain open. The
remaining nine scheduled weeks (8–16) are readiness-gated, not an acceptance date.
