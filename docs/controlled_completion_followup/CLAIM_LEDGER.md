# Claim ledger

22 September 2026. This ledger applies to the compound follow-up, not to every
other model or estimator in the repository.

| Statement | Status and evidence | Limit |
|---|---|---|
| Truncated signed multiplication preserves the digital output | Established algebraically; exhaustive small-width and production edge/inverse tests | Modular semantics do not prove financial overflow is absent |
| Source T counts improve about 1.91x at f=40 | Measured from emitted gates and independently reconciled | Level 4 only; no quantum-over-classical advantage |
| New source graphs represent the same digital law | Exact graph equality, five full source checks, four fused checks | Finite basis samples are not execution of the full pricing QPE |
| q=32 probability law, clipping/reset and analytic-control bias fit below $0.000029 | Deterministic expectation inequalities, interval evaluation, four stated models | Real financial arithmetic; additional arithmetic and policy certificates required |
| The Gaussian control identity transfers exactly | False for the finite law; a reachable guarded state disproves it | Its expected bias is now bounded instead |
| f=24 has a uniform $0.002 arithmetic error bound | False; interval-certified error greater than $0.0051738 | This is not a lower bound on expected error |
| f=40 arithmetic fits the remaining financial budget | Hypothesis; diagnostic errors are small | Uniform/expectation arithmetic proof still absent |
| Tight continuous moments can be used for the digital estimator | Conditional projection only | B squared is the currently rigorous digital replacement |
| All remaining estimator rotations have explicit accurate sequences | Established for 95 targets; exact-target interval verification and signed controlled-phase checks | No optimal synthesis claim; recipe is not full hardware execution |
| Physical scenarios meet allocated error under their premises | Conditional model, with exposure and finite factory retries charged | Empirical noise fit, layout, primitive timings and decoder reliability assumed |
| The current serial implementation passes a 10x latency screen | False under every reported screen | Upper schedules do not rule out different circuits or architectures |
| The implementation delivers a penny-accurate 99% continuous-model price | Unsupported | Arithmetic, finite-policy regret, surrogate accuracy and full execution unfinished |
| Significant quantum advantage exists for this project | Not established at evidence level 1 or 2 | Generic level-3 mean-estimation theorems do not establish this application crossover |
| No quantum algorithm can advantageously price these options | Unsupported | No problem-specific classical lower bound or quantum impossibility proof |
| The follow-up has independent technical review | Separate baseline, arithmetic, financial and FT reviews with findings tracked | Review is bounded and does not guarantee mathematical completeness |
| The work is a novel algorithm or guaranteed journal publication | Unsupported | A scoped benchmark/methodology contribution requires a distinct novelty/editorial case |

The existing manuscript's ideal-logical comparison is retained. The follow-up
does not inherit its error certificate, workload or claim merely because both
use option-pricing circuits.
