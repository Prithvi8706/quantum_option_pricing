# License-evidence scope

The release check inventories the repository LICENSE and the vendored csAE
notice without modifying either. It records exact bytes, not legal approval.

Before redistribution, a human must review the exact included source, notices,
dependencies and intended distribution. Installed environments and downloaded
papers are not automatically part of a release. Preserve vendor attribution;
do not infer permission to redistribute paper PDFs from local availability.

Dependency-license compatibility and complete third-party attribution remain
open release tasks. A successful file inventory cannot close those tasks.
