# Signed residual arithmetic follow-up

Pre-acquisition development protocol, 2026-09-21. This is a separate bounded
follow-up to the workspace/range study. Neither its sources nor results amend
that study's frozen archive. It tests a standard classical-control construction
inside a reversible arithmetic oracle; no new quantum primitive is asserted.

Retain D1/D2, q10, cutoff 4, $1/95%, 17 repetitions and the 10-million-call cap.
The fixed menu is width 48, fractional bits 24, degrees {8,12,16} and reduction
exponents {1,2,3}: nine configurations per case, all reported. Use shared clean
conversion scratch, efficient ripple aggregation, and both logical CX ledgers.
Conversion evidence comes from the completed primary archive with exact plan
matching. The degree-four control is the same archived polynomial and the
radius/offset are matched to each reflection case. Re-certify its finite-model
expectation using directed moments before acquiring resource comparisons.

At scale Q=2^24, normalize the sum-scaled poststrike integer using a quantized
reciprocal of dB, evaluate g(x)=(x+p4(x))/2 in fixed-point Horner arithmetic,
and multiply by quantized dB. The oracle encodes positive_part(delta)-control+H,
where H is a power of two strictly exceeding a certified residual bound.
The decoder restores the classical expectation and subtracts H's discounted
value. Charge normalization, coefficients, each product, scaling, all inverses,
offset uncertainty, loader and decoder errors. Do not clip signed residuals.

Prove the uniform bound using the analytic Chebyshev tail and the exact binary
coefficient bridge. Retain an exact negative residual witness showing why the
old unsigned selector is insufficient. The residual magnitude is an encoding
scale, not an additive payoff bias. Universal signed overflow and selector
bounds are required for every retained configuration.

Emit and count the complete control/shift/comparator oracle. Combine its actual
counts with pinned conversion/aggregation counts, including every inverse.
Report a conservative serial arithmetic depth bound separately from the
primary study's remapped dependency depth. Retain all allocated workspace;
do not claim reuse between conversion and control unless explicitly emitted.
Use at most 8 million gates / 4096 wires per new oracle and 100 million gate
applications per arithmetic component. Failed certification/caps remain rows.

Before freezing sources, test signed arithmetic, arbitrary flag states, coherent
phases, cleanup and inverses. Check actual production oracle inputs at archived
zero/max packed endpoints. Exhaust q1/q2 scalar finite targets separately,
including the restored expectation; these are diagnostics, not AE outcomes.

Primary outcome is minimum feasible control-cancelled total logical CX over
all nine choices, compared with the matched reflection and best primary
arithmetic plans. Report the conservative ledger, qubits, deterministic errors,
AE queries, failures and classical offset preparation work. These remain
quantum-route resource projections, not quantum-over-classical runtime claims.

Pin complete inputs, sources, environment and protocol in an exclusive archive.
Reconstruct every certificate, finite diagnostic and cost ledger independently;
re-emit selected full control oracles in the separate pinned environment.
Report actual reconstruction coverage and obtain independent AI math/code review.
Human novelty assessment and physical/confirmation admission remain open.
