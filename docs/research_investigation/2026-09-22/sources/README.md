# Local reading cache

The downloaded papers, extracted text, slide images and conference HTML in this
directory are retained locally and excluded from publication. `PROVENANCE.json`
records their hashes and primary-source retrieval links. The investigation's
citations point to those original sources; a fresh checkout does not contain
the copyrighted reading cache. The cache is not needed to run the financial
benchmarks or compiled arithmetic checks.

Earlier verification receipts refer to this local cache as evidence of reading.
Those historical receipts remain unchanged. A missing cached download in a new
checkout is not a missing quantum circuit or financial result.
