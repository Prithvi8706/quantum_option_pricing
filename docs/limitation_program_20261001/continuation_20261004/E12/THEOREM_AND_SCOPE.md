# E12: one bounded iid confidence-sequence construction

The selected implementation uses [Maurer and Pontil (2009), Theorem 4](https://www.learningtheory.org/colt2009/papers/012.pdf), whose actual assumptions are iid observations in [0,1]. Its sample variance equals the usual unbiased sample variance. For variance v, sample count n and one-sided failure delta, the upper radius is sqrt(2 v log(2/delta)/n) + 7 log(2/delta)/(3(n-1)). This construction uses two sides and fixed dyadic looks. It does not claim the paper itself proves an anytime theorem.

Fix alpha=1/2000. At n_j=2^j allocate alpha_j=alpha/(j(j+1)). Apply the theorem in both directions at failure alpha_j/2. The resulting radius uses log(4/alpha_j). The identity sum_{j=1}^m 1/(j(j+1))=1-1/(m+1) proves, without any independence between looks, that all intervals cover the same population mean simultaneously with probability at least 1-alpha. This also holds for all countably many looks. Intersect the intervals observed so far with [0,1] and retain that intersection between looks. Before the first look retain [0,1]. On the simultaneous event every retained interval contains the mean at every time, including an arbitrary stopping time. An empty intersection signals failure and returns the support fallback; it never certifies the target.

At zero observations the sample variance and mean vanish, but the upper endpoint remains min(1, 7 log(4/alpha_j)/(3(n_j-1))). Unseen rare events therefore never receive a zero moment certificate. The cap does not create a new uncorrected terminal look. The fixed-N comparator uses its separate terminal allocation on the same full diagnostic count trajectory.

For the financial residual Y(X,Z), freeze independently trained policy V. Let G_i=(X_i,Z_i1,...,Z_im) be independent identically distributed outer groups, with iid outer X_i and disjoint iid inner draws conditional on X_i. Then Q_i=mean_l Y(X_i,Z_il)^2 / B^2 are iid [0,1] variables with E Q_i=E Y^2/B^2, by the tower property. The inner residuals in a group need not be unconditionally independent. Squaring mean_l Y instead gives a different expectation and is forbidden. Shared inner factors between groups do not supply these hypotheses. Individual Sobol points are not this iid group corpus. A constant conditional mean alone is insufficient for the selected fixed-N theorem.

The implementation takes exact rational sufficient statistics and encloses confidence arithmetic outwards. [Python's Decimal documentation](https://docs.python.org/3.9/library/decimal.html) specifies correctly rounded logarithm, exponential and square-root operations. Adjacent representable values enclose these operations; rational conversions and arithmetic use directed rounding. This protects the confidence-bound calculation for its exact input statistics. It does not prove financial path-evaluation accuracy or PRNG independence. A separate 140-digit computation checks the fixed numerical corpus.

This is a conservative alternative to [Howard et al. (2021)](https://arxiv.org/abs/1810.08240). That paper's more general empirical-Bernstein sequence and conditional-mean hypotheses are not implemented or claimed here. No new inference theorem, quantum estimator, financial source, finance runtime comparison or quantum advantage follows. A negative cap/target admission result only closes the exact stopping design and does not rule out sharper sequences or a different complete-cost tradeoff.
