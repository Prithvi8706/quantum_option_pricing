# Verified primary-source bibliography

Search/verification date: **21 September 2026**. Twenty-five substantive sources
are included below; two peripheral PDE papers were screened only and remain
in the search log. This is a targeted assessment, not exhaustive priority
clearance. Publication metadata and the particular full-text version inspected
are different facts. Full author lists, reading locations, access qualifications
and implementation links are in the linked reviewer notes; `et al.` abbreviates
those verified lists rather than unknown authors.
