## F1 — Common compilation policy on existing selected oracles

**Question.** Does the D1/D2 route ordering survive when competing emitted
oracles use the same declared compilation/optimization policy, with comparable
width and depth accounting?

**Fixed target/inputs.** D1/D2 only, archived binary model, cutoff 4/q=10,
$1/≥95% ideal contract, seventeen repetitions, existing selected reflection
degrees 64/128, residual D1_00/D2_00 and their raw parents D1_28/D2_28.
Use the new classical label bridge explicitly. No new financial model, strike,
precision tuning, AE estimator, holdout case or paid hardware.

**Menu.** Six A-circuit implementations plus their required controls,
inverses and zero reflections. Compare (a) one common explicit U/CX logical
decomposition with the same permitted local cancellation rules, and (b) a
common Clifford+T synthesis model only if every non-Clifford rotation has a
proved common synthesis allowance. If (b) cannot be justified, report it as
unavailable; do not treat ideal rotations as zero-cost T gates. Select the
compiler version and optimization policy before reading new counts.

**Outputs.** Full component counts, allocated qubits, clearly comparable depth,
input/source/environment hashes, offset/phase/compilation classical work and
both old/new ledger reconciliations. Retain original results; emit into a
new exclusive archive with a committed executable protocol and producer.
There is no need to materialize billions of repeated AE gates: exact
composition after verified component/control accounting is sufficient for
the stated projection claim.

**Resource limits.** At most two CPU-hours total, 16 GiB working memory, six
selected A configurations and no production statevector or hardware jobs.
Stop and retain the partial record if a selected circuit/control cannot be
processed within those caps. Streaming arithmetic is permitted, but it must
obey the same decomposition/cancellation policy as the reflection counts.
An inability to support truly comparable depth is a reported limitation.

**Success/failure criteria.** Success for the scientific question is a complete,
reconciled comparison, even if the ranking changes. Retain a route-win claim
only if its new cost is lower under the stated common policy. If D2 reverses
again, rewrite the paper around compiler/comparator dependence. If only CX
ordering survives but depth/spacetime does not, retain the narrower CX claim.
No win percentage across six deterministic configurations is meaningful.

**Review.** Have a reviewer who did not implement the new compiler adapter
check controlled gates, cleanup, widths and error allocation. Request a
qualified human's scientific assessment only after the packet is concrete;
external contact still needs separate user authorization.

## F2 — Manuscript and human significance decision

Write a compact manuscript around the proposed claim, with one exact target
definition, one certificate chain, one matched-parent table, both resource
ledgers and a width/cost tradeoff figure generated from the full retained menu.
State all current limits alongside the primary result. The human questions
are in [the packet](HUMAN_EXPERT_PACKET.md). Positive tests/AI reviews do not
substitute for that judgment or author approval of a submission.

## Work deliberately not required for this decision

No broad parameter sweep, repeated control-degree tuning, paid device run,
new PDE or stochastic-volatility pivot, or attempt to rescue a quantum
advantage headline is justified. An optimized R2-style piecewise-polynomial
and pebbling arithmetic comparator becomes necessary if the paper claims
best-in-class arithmetic/reflection superiority; the current recommended
claim explicitly avoids that assertion. Stronger classical certified coverage
and physical runtime conversion belong to a later advantage project.
