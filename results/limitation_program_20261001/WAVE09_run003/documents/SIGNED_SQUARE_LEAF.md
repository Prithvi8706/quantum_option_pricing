# Exact signed square leaf

The same-SSA square experiment verifies an exact replacement for a multiplication
whose two arguments are the identical SSA value. The native circuit still has two
72-bit inputs and a 72-bit arbitrary XOR output. It reads only the first argument;
the second register remains present, untouched, and included in the resource count.
Whole-source dispatch must prove identical SSA identifiers. Runtime equality of two
unrelated values is insufficient justification for adoption.

The implementation is
[`signed_square.py`](../../research/controlled_source_completion/signed_square.py),
with prospective local receipt
[`A10_square_leaf_run001`](../../results/limitation_program_20261001/A10_square_leaf_run001/summary.json).
Only the declared Brent–Kung variant was tested. No precision or financial target
was changed.

## Arithmetic and cleanup

For a signed two's-complement word, assign each bit coefficient +1 except the sign
bit coefficient −1. Expanding its square yields positive diagonal terms at column
`2*i`, generated by a CX, and doubled off-diagonal terms at column `i+j+1`, generated
by a CCX. A sign-cross off-diagonal term is negative. Complementing its partial bit
and adding the fixed negative-weight modular correction represents that term exactly.

For width 72 and fraction 40, every column below 112 is retained. The 2,356 terms
comprise 56 diagonals and 2,300 off-diagonals; 40 off-diagonals are negative, and the
fixed correction is `2**72 mod 2**112`. Terms at columns 112 and above vanish modulo
`2**112`. Columns 0 through 39 remain in the carry-save tree and final prefix carry;
discarding them before propagation can change the retained result.

Fresh sum and carry wires preserve every carry-save input for reversal. The frozen
clean prefix adder sums the final two rows into a private product. The circuit copies
the 72-bit slice beginning at bit 40 into the arbitrary output, then reverses the
complete computation. Output bits never control gates, neither input is modified,
and all internal workspace returns to zero.

## Evidence and counted resources

All 21 tests passed in 17.04 seconds under the pinned Python 3.12.4 environment. The
protocol, implementation, producer and dependency snapshots were frozen before
tests and resource counts. Tests include:

- Every raw signed input, every output word, every fraction from 0 through width,
  and both forward and inverse execution at widths 1 through 6: 72,816 complete
  basis executions with independent integer square and floor expectations.
- 412 production inputs, including signed endpoints, powers and adjacent values,
  negative powers, and 128 seeded random words. Candidate forward/inverse execution
  and the historical general multiplier agree with the independent floor oracle.
- Literal diagonal/off-diagonal gate checks, untouched second argument, absence of
  output controls, exact compute/copy/reverse structure, and complete cleanup.
- Negative controls for omitted sign correction, prematurely discarded low-column
  carries, and unequal arguments; malformed or unequal concrete invocations are
  rejected by the separate contract predicate.

This is a 47.5% reduction in leaf T-gate work and a 3.54% reduction in leaf T-depth.
Counts use the actual emitted arrays, the existing exact seven-T CCX decomposition,
and all-to-all logical scheduling. Both full input registers and all saved carry
workspace are included.

The implementation's concrete equality predicate does not replace the required
same-SSA compiler proof. The full-source cost screen, existing qubit caps, source
replays, generic fallback, independent ledger, and adoption decision are separate
integration work. These leaf results do not establish physical runtime or quantum
advantage.
