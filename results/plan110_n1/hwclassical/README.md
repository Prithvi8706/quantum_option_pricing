# results/plan110_n1/hwclassical

These are the outputs of the N1 hardware/classical card. Read `research/plan110_n1/hwclassical/README.md` and `hw_classical_card.md` first.

- `hw_classical_card_v2.json` holds the numbers of record. It was produced by `research/plan110_n1/hwclassical/hw_classical_v2.py`, and the file records the SHA-256 of every input.
- `hw_classical_card.json` is the v1 output and is superseded. It used the raw T_C instead of the envelope, and its self-check failed. It is kept unchanged.
- `rows.jsonl` holds the incremental sub-result rows: anchors A01-A12 and the results.
